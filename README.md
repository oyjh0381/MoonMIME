# MoonMIME

MoonMIME is a byte-preserving recursive MIME message parser for MoonBit. The
project is under active development; the public v0.1 contract is documented in
`docs/SCOPE.md`.

## Development

```text
moon check --target all --deny-warn
moon test --target all --deny-warn
moon fmt --check
moon info
```
